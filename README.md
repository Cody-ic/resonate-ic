# 共振 · 集成电路与电子社区 R1 / 20261025

面向集成电路学院和电子学院同学，由同学自发建设、复用和完善的作品与学习社区，也欢迎其他方向的同学参与。以嵌入式、FPGA 和电子系统项目为主要内容。当前交付包含可运行后端与前端，源码与智能车固件分开存放。技术栈为 TypeScript、React、Vinext、Cloudflare Worker、D1（SQLite/Drizzle）与 R2。保留 starter 的第三方许可证。

## GitHub 源码与运行数据

独立源码仓库：<https://github.com/Cody-ic/resonate-ic>。源码上传不等于网站已部署，当前运行架构仍依赖 Cloudflare Worker、D1、R2、Durable Objects 和 Workflows；普通 VPS 部署需要另外适配这些服务。

```powershell
git clone https://github.com/Cody-ic/resonate-ic.git
Set-Location resonate-ic
npm ci
npm run build
```

随后按下文执行本地数据库迁移和初始化。根据 `.env.example` 创建被忽略的 `.dev.vars`，单独配置登录密钥和需要启用的服务。模板默认关闭付费 AI 调用、邮件发送及项目公开发布。仓库不包含账号、会话、用户上传附件、数据库、真实 API 密钥和本地审核结果；这些运行数据需要独立备份与迁移。既有第三方许可保留在各文件旁。

`tests/resource-review.test.mjs` 中的真实 PCB 集成样例属于可选私有测试文件；新环境缺失时明确跳过，可通过 `PCB_REVIEW_TEST_FILE` 指定对应的 A6.5 样例。其余合成样例检查仍然运行。

## 已实现

- 项目广场：嵌入式、FPGA、创意软件三个必选主类，来源/赛道/年份、平台、技术标签和关键词独立组合筛选。技术标签可多选（同时包含），无匹配项标灰禁选，已选条件始终可移除；目录先在 SQL 筛选，再分页。
- 自定义来源、细分类、平台、标签随修订送审。批准后进入公共词表；新技术标签默认放行，拒绝必须写明垃圾广告、辱骂、隐私或完全无关的明确依据。「其他」可保留、归入已有类或批准作者建议的新类。
- 公开个人主页（作品/资源/课程/帖子/回复）、个人简介与内容管理。草稿和回收站只在本人管理页显示；作者名字可进入主页。
- 邮箱密码注册登录、HttpOnly 会话、退出登录、持久化限流。保留平台登录；已登录的平台用户可明确选择为当前资料设置站内登录，保留内容归属。
- 项目/课程/资源/帖子/回复的作者编辑和可恢复删除；前端只对本人展示管理入口，直接输入他人编辑 URL 也不展示表单，后端再次检查归属。帖子修改留存历史，讨论与回复逐条经AI审核后发布，修改送审期间保留旧正文。
- 项目首屏展示仓库、资源包和附件，SmartWatch 显示配套课程入口。项目下直接发起讨论和回复。
- 项目正文仅项目介绍、硬件与环境必填，其他正文段落选填，可自定义大标题；主类、名称、简介、版本、许可仍为基础元数据。提交时汇总缺项、标红并可点击定位。资料常见类型自动命名，仅「其他资料」填写自定义名称。
- 独立的课程学习栏目、课程概览、模块目录、章节阅读与作者投稿。每个账号可以发布课程，可独立成课，也可关联某个公开项目的具体版本。
- 课程草稿、模块/章节编排、示例附件、新版本送审与工作台入口；公开课与未审核新修订相互隔离。项目页与课程页双向关联，不要求两边作者相同。
- 项目和开发资源分别收录；支持仓库、EDA、网盘、视频、演示与附件组合投稿。
- 草稿、新修订、送审、公开版本指针；审核较旧版本不能覆盖作者更新后的版本。
- D1 持久化账号、项目、版本、讨论、回复、附件元数据、审核、举报、申诉和决策记录。R2 保存附件。
- 作者权限、显式维护者角色、同源写入检查、服务端输入校验与发帖限流。
- 关闭独立论坛投稿，保留项目下讨论；评论和回复逐条实时先审后发。举报由AI核实问题确实存在且确有下架必要后处理，争议交人工。
- 精选项目必须先满足复现资料要求，再在竞赛/教学/深度/创意中至少选一项；开发资源不可加入精选。
- DeepSeek 审核适配器：原文引用校验、版本摘要、后台触发、争议队列、失败保留、月度调用与费用预留硬上限。配置未启用时保持排队，不调用付费接口。

## 本地运行

Node >=22.13（本次使用24.18）。依赖锁定在 package-lock.json。

```powershell
Set-Location 'D:\智能车\网站\学院作品站_20261025'
npm ci
npm run build
Get-ChildItem drizzle/*.sql | Sort-Object Name | ForEach-Object {
  node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file $_.FullName
}
node scripts/seed-local.mjs --local
node scripts/seed-course-local.mjs --local
python -X utf8 scripts/backfill-classification.py --local
node scripts/configure-local-auth.mjs
npm run dev -- --hostname 127.0.0.1 --port 5173
```

迁移只在新数据库执行一次。新增表或字段先修改 db/schema.ts，再运行 `npm run db:generate` 并检查生成的新增迁移，不修改已经应用过的 SQL。公开数据与草稿必须备份数据库及附件，不能只备份源码。

本机地址 http://127.0.0.1:5173 。`/login`、`/register` 是站内邮箱密码入口，使用 Better Auth 与独立认证表；内容所属资料 ID 仍由服务端确定。密码使用库的默认散列，不保存明文。会话有效期7天，退出后失效；敏感认证接口使用数据库原子限流，开发与生产均启用。正式部署设置随机 `BETTER_AUTH_SECRET` 和网站 HTTPS 地址 `BETTER_AUTH_URL`；不要复用本机密钥。

`/signin-with-chatgpt?return_to=/dashboard` 仍保留平台登录；本机此入口使用 loopback 测试身份 `local_seedy`，正式托管由平台提供可信身份头，不能把模拟登录部署为公开注册。平台账户可在「设置登录」中勾选关联当前资料；普通新注册不会自动取得其他人的内容。生产默认忽略平台身份头，防止独立部署时被伪造；仅在能剥离客户端伪造头的可信平台代理后设置 `PLATFORM_AUTH_ENABLED=true`。本地测试平台头由 Vite 插件剥离后注入。

邮箱验证和密码找回已通过 Microsoft Graph 接入。新克隆默认关闭邮件；完成授权并启用后，注册验证码、补验证和密码重置走真实邮件队列。是否要求验证后登录由独立开关控制，未验证邮箱不能用于身份认证或账号找回。接入步骤见 [邮箱配置](docs/mail-setup.md)。
本地维护者可在忽略的 `.dev.vars` 中设置 `ADMIN_USER_IDS=local_seedy`，重启 dev 后生效。未设置时没有任何账号自动获得管理权限；正式环境填写 `/api/me` 返回的稳定资料ID，不使用昵称或邮箱。

`seed-local.mjs` 仅为本地开发导入用户提及的4个项目概览，标记资料待完善，均非精选。没有捏造奖项、实车验证、复现记录或论坛用户。不会覆盖已经存在的项目；不在迁移中加入种子数据。

`seed-course-local.mjs` 导入 SmartWatch 教程 v0.2.0 预览版（79章、88个HTML页面），并为手表项目追加公开工程说明修订，保留初始收录记录。可在 `/courses` 找到课程；`/courses/new` 是所有作者共用的课程投稿入口。导入器不覆盖作者已经开始编写的新草稿。

## 课程内容与导入

普通课程支持模块、章节纯文本（含代码）、公开资料链接与配套附件；每章标注电脑、开发板或项目硬件实验条件。单套最多30个模块、200章，单章正文24000字符，单次课程请求1MiB。草稿也校验基础元数据；送审另检查学习目标、前置基础、学习方法与每章内容。连载中课程可以发布。课程使用既有不可变修订和审核表，以 `kind=course` 与项目、资源区分，不再复制一套版本系统。

站内章节按文本渲染，不执行投稿者的 HTML/JavaScript。现有外部教程可提供章节链接或ZIP/PDF附件，外链不会由服务器自动抓取。SmartWatch 交互原版是维护者审阅后导入的受信静态快照，映射绑定具体课程修订；普通投稿不能填写或取得这个映射。

```powershell
python -X utf8 scripts/import-smartwatch.py --source 'D:\STM32Dev\SmartWatch\publication\SmartWatch'
node scripts/seed-course-local.mjs --local
```

导入仅复制教程文件，排除缓存和隐藏文件；原始项目不修改。`public/course-content/smartwatch/<版本>/` 保存完整网页、图解与示例，复制页面增加返回课程/项目的导航。`content/smartwatch-imports/` 保留各版清单，记录原始文件和实际服务文件的SHA256；`trusted-courses.json` 保存各公开修订的静态映射。已有版本文件不能覆盖，更新需使用新版本。当前最新源文件集合摘要为 `5f28f99c2456603dbe2f653960d7cee23196f561de1f30f65e73dd4e62ba34f3`。

SmartWatch 原版阅读进度只存在当前浏览器，不会上传账号。其他作者的站内课程当前提供阅读与前后章导航，尚无跨设备学习进度。关联项目时固定公开修订；课程页返回该修订，避免工程更新后失去对照。

### 发布、争议与下架

| 情况 | 作品正式审核 | 项目讨论、回复 |
|---|---|---|
| 明确通过 | 发布 | 发布 |
| 有依据但有争议 | 先发布、显示待人工复核并提醒管理员 | 隐藏并交人工复核 |
| 明确广告、隐私泄漏、辱骂等 | 不发布，说明原因 | 不发布，说明原因 |
| 接口故障、超时、格式或证据校验失败 | 保持原公开版本，交人工处理 | 新内容不公开，修改保留旧正文 |

表中公开操作仅在解除上架暂停后生效；暂停期间仍会形成完整审核结果、分类方案和通知，人工复核不受限制。管理员下架必须填写理由，保留审计与作者通知；只有管理员明确解除下架锁后才能恢复，AI和作者恢复操作均不能绕过。

- 作品通道加载 `skills/project-review/SKILL.md` 和输出协议，处理作品、课程、开发资源和技术问题核查；项目安排在低价时段，讨论提交后立即触发。
- 讨论通道加载 `skills/project-discussion-review/SKILL.md` 和输出协议，处理评论、回复、举报和超过20人推荐后的优质核验。一账号一票，允许推荐自己；修改通过后重新累计推荐。
- 新标签以放行为主，明显广告、辱骂、隐私或完全无关时才剔除。平台可凭明确证据把错选 CH 替换为词表中的 ST；修正方案在作者通知中单列。
- 技术反馈独立于评论能否发布：带辱骂的评论可以被拒绝，同时将中性问题交给项目通道。相同项目、版本和待核查问题合并任务；核查未定位时温和邀请评论者补充，作者反馈文案经人工确认，不把投诉当作缺陷认定。
- 每次AI决定记录规则版本、规则摘要、投稿摘要、实际读取文件和原文证据。模型超时或失败不自动重复付费重试。

### 通知与邮箱

`/notifications` 提供私有站内收件箱，导航显示未读数。正常评论公开后通知工程作者；评论下的回复只向评论作者发站内通知，这一限制在后续技术反馈文案获准时也保持。自己回复自己不重复提醒。

正式作品审核必须生成作者文案；无问题时简短祝贺。完善建议、争议说明和待核实技术反馈先成为管理员可编辑确认的草稿，作品无需等文案确认才公开。拒绝或等待时先给固定状态提示。历史试审文案保留原标记；新审核一律使用正式通知流程，并在暂停上架时说明公开状态未更改。普通评论的邮件分流规则继续保持。

邮件发送队列、Microsoft Graph适配器、验证码与找回密码界面已实现；2026-10-27 已完成本机 Outlook OAuth 授权和真实投递联调。GitHub 克隆及其他部署仍需单独提供私有授权配置。普通用户只向已验证地址投递邮件；管理员提醒地址由 `ADMIN_EMAILS` 配置。未配置邮箱服务时验证码接口明确不可用，站内通知照常工作。验证码5分钟有效、散列存储且限制尝试次数，邮件队列中的验证码正文加密，过期或发送成功后清理。发送结果不确定的邮件需管理员核对后决定重试。

### 人民币预算

- 作品：`PROJECT_AI_MONTHLY_BUDGET_MICROS=30000000`，即每月30元。
- 讨论：`DISCUSSION_AI_MONTHLY_BUDGET_MICROS=30000000`，即每月30元。
- 两路合计：`AI_TOTAL_MONTHLY_BUDGET_MICROS=50000000`，即每月50元。
- 费用单位为微元人民币，1000000微元=1元；按北京时间自然月统计。两个Key共享数据库费用账本，每次调用前用一条条件SQL同时检查单路预算、共享预算和调用数上限，包含执行中与失败请求的预留，防止并发超出总额。
- `AI_INPUT_CNY_PER_MTOK=2`、`AI_OUTPUT_CNY_PER_MTOK=8`：当前Flash高峰输入未命中与输出单价，每百万token。即使低价时段也按高峰价预留，输入字节数加协议余量作为token上界，输出预留8192token；不把缓存或低价优惠提前退回预算。预留可能高于实际扣费。
- 费用到限后保留待审核，不改为直接发布。单路或共享额度为0时不允许付费调用。`*_AI_MONTHLY_MAX_CALLS` 是额外异常调用保护，不代替费用上限。本地当前各路最多5000次，实际先受金额约束。

价格及峰谷时间以[DeepSeek官方价目](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)为准。当前峰时为北京时间工作日9–12点、14–18点，其余及周末低价；法定节假日可通过 `AI_OFFPEAK_DATES` 补充。修改模型或供应商价格后应同步更新配置。本地账本只涵盖本网站发起的调用，不能限制在其他程序直接使用相同Key的消费。

### 队列与附件范围

成功写入后由Worker后台触发队列，正式Worker还配置每5分钟调度；本机Vite预览不会自动执行云端Cron，需要请求或管理员手动唤醒。作品审核也遵守低价时段。密钥、月度额度或共享预算缺失时保留待审。

附件最多10MB/个、100MB/账号、每小时12次上传，下载使用attachment和nosniff。支持读取文本源码及常规ZIP内文件，摘要校验、路径检查、条目数、展开体积及读取次数均有限制，不执行或落盘解压投稿代码。模型通过只读工具选择读取文件，记录已读路径。作者封面以原生图像消息交模型检查，其他二进制不自动解析；精选审核会读取公开GitHub仓库，其他普通外链不自动抓取，没有病毒扫描、自动编译或实物验证；不能把投稿文字审核当作完整工程验收。过长输入、不可读取资料或证据校验失败会交人工，不截断后冒充已审遍。

## 个人与管理界面

- 个人资料只在点击“编辑资料”后以弹窗编辑，工作台分别显示我的内容和审核记录。
- 消息页使用列表与正文阅读区，旧通知自动解析到相关作品或课程；另提供直接定位具体审核记录的链接。
- 作品标题附近提供管理员下架按钮，要求简短理由并保留锁定及通知；课程和讨论同样按权限显示管理入口。
